# 구름드라이브 (Gureum Drive)

Windows용 rclone GUI. 계정 추가부터 드라이브 마운트까지 콘솔 입력 없이 관리합니다.

기존 CloudDock의 새 이름입니다. 기존 계정 설정 호환성을 위해 설정 폴더명은 유지합니다. 실행 파일은 GureumDrive.exe입니다.

## 실행

`dist/GureumDrive.exe`를 실행하세요. 같은 폴더에 `rclone.exe`가 필요합니다.
실제 드라이브 연결에는 [WinFsp](https://winfsp.dev/rel/) 설치가 필요합니다.
Windows 10/11 x64, .NET Framework 4.8 환경을 대상으로 합니다.

앱 시작 시 WinFsp 설치 여부를 확인합니다. 미설치 상태에서는 공식 다운로드·설치 순서를 안내하고 연결 버튼을 ‘WinFsp 설치하기’로 표시합니다. 이 버튼은 같은 설치 안내 팝업을 엽니다. 계정 추가·제거는 계속 사용할 수 있습니다. 설치 후에는 트레이 메뉴에서 앱을 종료하고 다시 실행하세요. 설치 여부 다시 확인 버튼도 제공하며, 실행 중 새로 설치된 경우에는 재시작이 필요하다고 표시합니다. 설치 파일은 자동 실행하거나 동봉하지 않습니다.

이 의존성은 클라우드별 차이가 아니라 Windows에서 `rclone mount`를 사용하는 방식의 공통 조건입니다. 계정 설정과 API 작업에는 WinFsp가 필요하지 않습니다. WinFsp는 공식 컴포넌트를 사용하며 별도로 포크하지 않습니다.

1. **클라우드 추가**에서 Google Drive·OneDrive 카드를 선택합니다. 그 외 서비스는 **다른 서비스**에서 검색합니다.
2. **이 연결을 구분할 이름**은 앱에 표시할 별명입니다. 자동으로 제안되며, ‘개인용 원드라이브’처럼 한글로 바꿀 수 있습니다. 이메일이나 로그인 ID가 아닙니다.
3. **로그인으로 계속**을 누르고 열린 브라우저에서 인증합니다. Google Drive는 공용 앱 ID 사용 여부를 확인하며, 직접 발급한 ID를 선택하면 앱 ID와 비밀키를 입력합니다. 서비스별 요구 조건은 화면의 원문 번역과 공식 발급 안내를 확인하세요. OneDrive의 앱 ID는 해당 도움말의 기본 조건을 따릅니다. OneDrive의 드라이브 선택 등 추가 질문에 답합니다.
4. 인증 뒤 **드라이브 연결** 화면에서 드라이브 문자, 클라우드 폴더(선택), 캐시 크기를 지정합니다. ‘나중에 연결’을 선택하면 계정만 저장합니다.
5. 파일 탐색기에서 파일을 열고 저장합니다. **연결 해제**로 마운트를 해제합니다.

창 닫기는 트레이로 숨기기입니다. 파일을 닫고 트레이 메뉴에서 종료하세요. 업로드 대기·진행·실패 또는 미확인 캐시가 있으면 경고하고, 기본 선택은 해제·종료 취소입니다. 경고를 확인하고 진행하면 전송이 중단될 수 있습니다. 캐시는 지우지 않지만 재전송은 보장하지 않으며, 재시도에는 같은 계정·원격 폴더·캐시 설정으로 다시 연결해야 합니다. 읽기 전용으로 열린 파일까지 모두 감지하지는 않습니다. 캐시의 업로드 대기 파일을 수동 삭제하지 마세요. 캐시 한도는 열린 파일과 전송 대기 파일 때문에 초과할 수 있습니다.

Windows 종료 요청 시 연결이나 진행 중인 작업이 남아 있거나 상태를 확인하지 못하면 종료를 보류합니다. 트레이에서 앱을 종료한 뒤 Windows 종료를 다시 시도하세요. 이 경로에서는 백그라운드 언마운트를 시작하지 않습니다. 계정 제거 시 해당 계정의 캐시를 확인하고 미전송·미확인 자료가 있으면 추가 경고합니다.

로컬 설정을 일시적으로 읽지 못하면 표시에는 마지막 정상값을 사용하고 저장은 차단합니다. 손상된 JSON은 별도 `.corrupt-*` 파일에 백업한 뒤 기본값으로 처리합니다. 백업을 만들지 못하면 저장을 차단합니다. 인증 중단이나 완료 여부를 확인하지 못한 경우 계정 설정을 보존하며, 이전 인증이 끝났는지 확인하기 전에는 계정 추가·제거를 막습니다. 시작 실패 진단에는 stderr 원문 대신 허용된 오류 분류만 표시합니다.

## 구현 범위

- 설치된 rclone의 전체 서비스 목록을 동적으로 조회하고 검색
- rclone의 비대화형 구성 프로토콜에 기반한 GUI 질문/선택/비밀번호 입력과 OAuth
- 계정 목록, 드라이브 마운트/해제, 탐색기 열기, 계정 설정 제거
- 쓰기 및 읽기 디스크 캐시(full), 네트워크 드라이브 모드, 읽기 전용
- 계정별 드라이브 문자/경로/캐시 설정 저장, 트레이, 중복 실행 방지
- 표시 별명과 내부 연결 ID 분리. 기존 연결의 내부 ID는 유지하며, 별명은 names.json에 별도로 저장합니다.
- 앱 전용 rclone 데몬: 루프백 주소 + 실행마다 생성한 인증값, 프로세스 종료 시 자식 정리
- 설정 위치: `%LOCALAPPDATA%\CloudDock`. 기존 rclone 설정과 독립적이며 로그인 정보는 rclone.conf에 저장됩니다. rclone obscure는 암호화가 아니며, 이 폴더는 현재 사용자·SYSTEM·관리자만 접근하도록 설정합니다.

전체 목록은 **rclone이 구성할 수 있는 서비스**를 의미합니다. 모든 서비스가 동일한 쓰기·이름 변경·용량 조회 기능을 지원하는 것은 아닙니다.

## 언어

Windows 표시 언어가 한국어(ko)이면 한국어, 그 외 로케일이면 영어로 표시합니다. 메뉴·버튼·상태·오류·계정 추가·인증·마운트 설정에 동일한 정책을 적용합니다. `GureumDrive.exe --lang=ko-KR` 또는 `--lang=en-US`로 실행 시 언어를 지정할 수도 있습니다. 계정 별명, 입력값, API 식별자와 서비스 브랜드는 자동으로 번역하거나 변경하지 않습니다.

기본 설정 항목 140종의 한국어 제목을 제공합니다. rclone v1.76.0의 공개 옵션 도움말과 선택지 설명은 한국어 번역문을 먼저 표시하고, 그 아래에서 **원문 보기**를 펼쳐 비교할 수 있습니다. 앱의 추가 설정 안내는 원문 번역과 구분합니다. 긴 번역문은 스크롤해서 끝까지 읽을 수 있습니다. 영어 모드에서는 rclone의 원래 설명을 사용합니다. 예/아니오 표시는 언어에 맞게 바꾸지만 엔진에는 기존 true/false 값을 전달합니다.

UI 문구의 영어 카탈로그는 `src/Strings.en.json`, 원문별 한국어 번역은 `src/RcloneHelp.ko.json`, 검토한 주요 번역은 `src/ReviewedHelp.ko.json`, 추가 설정 안내는 `src/ConfigText.cs`에서 관리합니다. 번역은 빌드 시 실행 파일에 포함하므로 앱 실행에 번역 서버·API 키·로컬 모델은 필요하지 않습니다. 새 버전 rclone의 미등록 도움말은 번역이 없음을 표시하고 원문 보기를 제공합니다. OneDrive의 실제 계정 이름·드라이브 URL이 포함된 확인 문장은 로컬 템플릿으로 번역하며 번역 서버로 보내지 않습니다.

오류창은 한국어 오류 설명과 해결 방법을 먼저 보여주고 기술 원문은 접어 둡니다. WinFsp 미설치 오류는 공식 다운로드 버튼과 설치·재실행 순서를 제공합니다.

번역 리소스 재생성: 공개 `rclone config providers` 출력을 `tools/providers.json`에 저장한 뒤 `scripts/translate_help.py`와 `scripts/review_help.py`를 실행합니다. `scripts/check_help.py`로 누락과 숫자·코드·URL 보존을 검사합니다. 초벌 번역은 설치된 로컬 Ollama 모델을 사용하며 주요 설정 44종은 검토본으로 교체합니다. 전체 고급 설명을 사람이 모두 교정한 것은 아닙니다. 옵션 값·코드·URL은 보존하고 원문을 함께 제공합니다.

MYBOX는 기본 백엔드가 아닙니다. 앱에 공식 API와 외부 mybox-s3 중계기 연결 안내를 넣었습니다. 중계기 설치/실행 자동화와 MYBOX 직접 연동은 미구현입니다. 토큰 만료, 공유받은 폴더·암호 폴더 제한은 네이버 API 정책을 따릅니다. 실제 MYBOX 마운트 호환성은 검증 전입니다.

자동 로그인 시작, 시작 시 자동 재연결, 파일 전송 화면, Linux 패키지는 아직 없습니다. 클라우드 계정 실연결과 WinFsp 마운트는 사용자 환경에서 검증해야 합니다.

## 빌드

PowerShell에서:

```powershell
.\setup-rclone.ps1
.\build.ps1
```

추가 NuGet 의존성 없이 Windows .NET Framework C# 컴파일러를 사용합니다. setup 스크립트는 rclone v1.76.0 공식 ZIP과 SHA256SUMS를 내려받아 일치 여부를 확인합니다. WinFsp는 사용자가 공식 설치 프로그램으로 설치합니다.

엔진 통합 점검: `dist\GureumDrive.exe --self-test` 실행 후 `dist\self-test.txt` 확인. 임시 폴더에서 로컬 백엔드와 설정 프로토콜만 검사하며 클라우드 계정은 사용하지 않습니다.

회귀 검사: `dist\GureumDrive.exe --check-localization=tools/providers.json`. `dist\localization-test.txt`, `dist\shutdown-test.txt`, `dist\reliability-test.txt`를 확인하세요. 설정 잠금·손상 복구, 계정별 캐시 분리, 모의 RC 취소 경쟁 조건을 검사하며 실제 계정이나 마운트는 변경하지 않습니다. 임시 검사 자료는 보존합니다. 실제 OAuth·WinFsp·Windows 종료 동작은 별도 검증이 필요합니다.
